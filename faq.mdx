---
title: FAQ
description: Common questions about getrequest.
---

<AccordionGroup>

  <Accordion title="How long are my requests stored?">
    Log retention depends on your plan:

    | Plan | Retention |
    |------|-----------|
    | Free | 7 days |
    | Dev | 30 days |
    | Pro | 30 days |
    | Gro | 30 days |

    Logs older than your retention window are automatically deleted. Upgrade your plan before the window closes if you need to keep a specific log entry.
  </Accordion>

  <Accordion title="Does getrequest add latency to my API?">
    For Forward endpoints, getrequest adds less than 5ms of overhead per request. The 3-second upstream timeout is on your backend, not on getrequest itself.

    For JSON endpoints, there is no upstream call — the response is returned directly from edge infrastructure with sub-millisecond overhead.
  </Accordion>

  <Accordion title="What happens if my backend is slow or unresponsive?">
    Forward endpoints wait up to **3 seconds** for your upstream to respond. If the upstream exceeds that, getrequest returns `504 Gateway Timeout` to the caller. The request is still logged with the timeout noted, and you can replay it once your backend recovers.
  </Accordion>

  <Accordion title="Can I send binary payloads (images, files)?">
    Yes. getrequest forwards any request body, including binary data. Binary payloads are base64-encoded in storage. The maximum body size is **1 MiB**.
  </Accordion>

  <Accordion title="Is my API key the same as my project URI?">
    No — these are different things.

    - **API key** — authenticates you to getrequest's API Gateway. Include it as the `x-api-key` header in every request. Found in **Settings → API Key**.
    - **Project URI** — part of your endpoint URL (e.g., `ddfkU760XMs2z7te`). It identifies which project a request belongs to. Found on your project page.
  </Accordion>

  <Accordion title="What happens when I exceed my monthly quota?">
    Requests that exceed your monthly quota are rejected at the API Gateway level with `HTTP 429 Too Many Requests`. They do not reach your backend and are not logged. Upgrade your plan to restore access immediately — mid-period upgrades are prorated.
  </Accordion>

  <Accordion title="Can I replay requests on the Free or Dev plan?">
    No. Request replay requires **Pro or Gro**. On Free and Dev plans, you can view and inspect all captured logs but cannot re-fire them.
  </Accordion>

  <Accordion title="Do shareable links require the recipient to have an account?">
    No. Anyone with the link can view the request and response — no login, no account, no permissions. Links expire after 30 days or when you revoke them.
  </Accordion>

  <Accordion title="Can I use getrequest with multiple environments (dev, staging, prod)?">
    Yes. Create a separate **project** for each environment. Each project gets its own URI and its own set of endpoints. Your API key is shared across all projects.
  </Accordion>

  <Accordion title="Can multiple team members access the same project?">
    Team access is coming soon. Currently, each account has its own projects and endpoints. Share log links with teammates in the meantime — they can view the full request and response without needing access to your account.
  </Accordion>

  <Accordion title="How do I rotate my API key?">
    Go to **Settings → API Key** and click **Regenerate**. Your old key is immediately invalidated. Update any clients using the old key before regenerating.

    You can regenerate up to **6 times per hour**.
  </Accordion>

  <Accordion title="Is getrequest suitable for production traffic?">
    Yes. Forward endpoints are used in production by teams that need full request visibility and replay capability. getrequest is built on AWS API Gateway and Lambda, designed for high availability and low latency.
  </Accordion>

</AccordionGroup>
