This walkthrough uses a payment webhook as the example — exactly the kind of request you can't afford to lose — but every step here works identically for any endpoint you create.

## Step 1: Create an endpoint

1. Sign in to [app.getrequest.io](https://app.getrequest.io) and open your project.
2. Click **New Endpoint**.
3. Fill in the fields:

| Field | Example | Notes |
|-------|---------|-------|
| Name | `Stripe payment webhook` | Human-readable label |
| Slug | `/webhooks/stripe` | Appended to your project URL |
| Method | `POST` | GET, POST, PUT, PATCH, DELETE |
| Action | `JSON` | Start with JSON to capture the event without touching your backend yet |

4. Paste a sample response body — this stands in for whatever your backend would normally reply with once it's wired up:

```json
{
  "received": true
}
```

5. Click **Create**. Your endpoint is live immediately.

Your endpoint URL will look like this:

```
https://e.getrequest.io/ddfkU760XMs2z7te/webhooks/stripe
```

<Note>
  Your project URI (`ddfkU760XMs2z7te` above) is unique to your project. Copy it from the project page.
</Note>

## Step 2: Send your first request

Grab your **API key** from [Settings → API Key](https://app.getrequest.io/settings/api-key) and simulate a payment event arriving:

<CodeGroup>

```bash cURL
curl -X POST https://e.getrequest.io/{project_uri}/webhooks/stripe \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "evt_1Nx29mp2xJ9AbCd",
    "type": "payment_intent.succeeded",
    "data": {
      "object": { "id": "pi_3Nx29mp2xJ9AbCd", "amount": 4999, "currency": "usd", "status": "succeeded" }
    }
  }'
```

```javascript JavaScript
const response = await fetch('https://e.getrequest.io/{project_uri}/webhooks/stripe', {
  method: 'POST',
  headers: {
    'x-api-key': 'YOUR_API_KEY',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    id: 'evt_1Nx29mp2xJ9AbCd',
    type: 'payment_intent.succeeded',
    data: {
      object: { id: 'pi_3Nx29mp2xJ9AbCd', amount: 4999, currency: 'usd', status: 'succeeded' },
    },
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    'https://e.getrequest.io/{project_uri}/webhooks/stripe',
    headers={
        'x-api-key': 'YOUR_API_KEY',
        'Content-Type': 'application/json',
    },
    json={
        'id': 'evt_1Nx29mp2xJ9AbCd',
        'type': 'payment_intent.succeeded',
        'data': {
            'object': {'id': 'pi_3Nx29mp2xJ9AbCd', 'amount': 4999, 'currency': 'usd', 'status': 'succeeded'},
        },
    },
)

print(response.json())
```

```php PHP
$client = new \GuzzleHttp\Client();

$response = $client->post('https://e.getrequest.io/{project_uri}/webhooks/stripe', [
    'headers' => [
        'x-api-key' => 'YOUR_API_KEY',
        'Content-Type' => 'application/json',
    ],
    'json' => [
        'id' => 'evt_1Nx29mp2xJ9AbCd',
        'type' => 'payment_intent.succeeded',
        'data' => [
            'object' => ['id' => 'pi_3Nx29mp2xJ9AbCd', 'amount' => 4999, 'currency' => 'usd', 'status' => 'succeeded'],
        ],
    ],
]);

echo $response->getBody();
```

</CodeGroup>

You'll get back the JSON you configured:

```json
{
  "received": true
}
```

## Step 3: Verify the request arrived

Open your project in the dashboard and click **Logs**.

You'll see the request you just sent — method, status, path, and duration. Click the row to inspect:

- **Request** — full headers, query params, and body
- **Response** — status code, headers, and body
- **Timing** — how long it took end to end

This is exactly what getrequest captures for every request it receives — a quick test like this one, or a real event from a payment provider. Nothing is dropped, even before your backend ever sees it.

<Tip>
  On Pro and Gro, you can click **Share** on any log entry to generate a public link — useful for bug reports and team debugging.
</Tip>
